## 🧭 About me

I've spent the last few years moving through different areas, finance, inventory, administrative, marketing and data, and in each one I noticed the same thing motivated me: understanding a problem and solving it in a structured way. That realization is exactly what brought me back to programming.

I had a first contact with software development a long time ago, at Senai, but back then I gave up because of how repetitive writing line after line felt. I picked it back up in August 2026, this time in a very different way, with better tools, more focus on logic and less on repetitive typing.

I started with programming logic in JavaScript and I've been moving forward one step at a time, without rushing to skip stages. The repositories on this profile show what I've been practicing along the way.
